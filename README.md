Ebola Prevention FAQ: DRC

A lightweight static website built with PHP that answers frequently asked questions about Ebola virus prevention in the Democratic Republic of the Congo (DRC). It aims to give communities quick, clear, and accessible guidance on how the virus spreads, how to recognize symptoms, and how to protect yourself and others.

Features
Clear, easy-to-read FAQ on Ebola prevention
Simple static structure, no database required
Lightweight and fast, even on slow connections
Responsive layout for mobile and desktop

Topics Covered
What Ebola is and how it spreads
Common signs and symptoms
Everyday prevention measures (hygiene, safe contact, safe burials)
What to do if you suspect a case
Where to find official help and information

Tech Stack
PHP: page structure and includes
HTML / CSS: layout and styling
JavaScript (optional): small UI interactions such as expandable questions
